# 魔王軍にも入国審査があるってこと！？

ブラウザ向けの入国審査ゲーム試作。依存ライブラリ不要のHTML / CSS / JavaScriptで実装。

**[ゲームを遊ぶ](https://okasinomatioka.github.io/maou-border-inspection/)**

## 開発と公開

ゲームの変更は `dist/` に加えます。公開時に `docs/` へコピーし、GitHub Pages が `main` ブランチの `/docs` を配信します。

```sh
npm test
npm run build
```

修正から公開までまとめて行う場合（GitHubへのpush権限が必要）：

```sh
npm run publish:pages -- "変更内容を記入"
```

テスト成功後に公開ファイルを更新し、コミット・pushします。GitHub Pagesの配信完了はリポジトリのActionsまたはPages設定で確認してください。この会話で修正を依頼すれば、この公開先へ更新できます。

旧URLのセーブデータはブラウザ内で保存されているため、新しいURLへ自動移行はされません。

## 起動

```sh
python3 -m http.server 4173 --directory dist
```

http://localhost:4173 を開く。ES modulesを使うため、HTMLの直接ダブルクリックではなくHTTPで配信する。

## 内容

- v1.3：任務終了後のエンディングを追加。成功4種・敗北2種、各3場面の物語と最終戦績。読み返し・スキップ・途中保存に対応し、更新前にクリア済みのセーブでも閲覧可能。
- 全8日、1日3〜5名（計31名）、各人物に動くSVG立ち絵。
- 毎日1種の検査道具を追加。書類・印章・言語・荷物・変装・魔力・方言・王印を検査。
- 入国許可、拒否、2枠の隔離、入国者の再検査、追放、殺害。
- 追放は兵力8、殺害は15を消費。隔離は1名につき3兵を一時拘束。
- 勇者3/4/5/6名以上で死亡率20/35/55/75%。兵力10減ごとに5ポイント追加、上限95%。勇者2名以下では死亡判定なし。
- 毎夜、勇者1名につき兵力3を消耗し、その後判定。食料4を消費。不足なら兵力18減。兵力0で防衛線崩壊。
- 味方は食料2、補給商人は5を提供。衛兵は兵力12、回復術師は8を回復。
- 第8日の夜を生き残ればクリア。localStorageへの自動保存と任意の効果音。
- 検査道具は数字キー1〜8でも操作可能。
- v1.1：31名それぞれに専用のあいさつを追加。共通語・ゴブリン語・角族語・獣人語・夜語・スライム語・山岳ゴブリン語の7言語。
- 吹き出しで「あいさつ」「来訪の目的」「荷物について」を切り替え可能。魔族語辞典は基本5言語の単語、万能翻訳機は発言ごとの全文を翻訳。検査済みの翻訳は質問変更時に更新。
- v1のセーブも続行でき、審査状況・兵力・隔離者を維持したまま会話データを更新。
- v1.2：自由入力の質問欄を追加。種族・言語・職業・目的・荷物・書類についての単純な質問に「はい」「いいえ」で指さし回答。人物ごとに直近8件を保存し、隔離や再開後も確認可能。
- 自由入力はローカルの対応語と文型で判定（外部AI/APIは使用しない）。未知の内容、複合質問、自由記述を求める質問は言い換えを案内し、返答を捏造しない。否定形は否定された命題が正しければ「はい」。
- 返答は自己申告。潜入者は正体や隠した武器を否認する場合がある。書類・鏡・透視などの物的な検査結果は変化しない。

## 検証

```sh
node --test tests/engine.test.mjs
node --test tests/dialogue.test.mjs
node --test tests/questions.test.mjs
node --test tests/endings.test.mjs
```

`dist/engine.mjs` にルールとステージ生成、`app.js` にUI、`art.js` にアニメーション立ち絵と城のSVGを収録。画像はすべて同梱のベクター描画。日本語Webフォントを取得できない場合は端末の明朝・ゴシックにフォールバック。

## 試作上の調整項目

入国直後の城内勇者数は表示される。推理の難易度を上げる場合は翌朝まで秘匿する設計に変更可能。シナリオと敵の配置は固定、夜の判定はゲームごとのシードで変化。リロードしても同じ保存時点から同じ判定結果になる。
